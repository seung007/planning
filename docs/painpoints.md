# 페인포인트 — 스마트스토어 셀러의 카피 고충

## 1. 시간이 너무 오래 걸린다

상품 설명 카피 1개를 쓰는 데 평균 30분~1시간 소요.
신상품을 매일 올리려면 카피 작성만으로 반나절이 사라짐.

## 2. "잘 팔리는 표현"을 모른다

어떤 단어나 문장이 클릭과 구매를 유도하는지 알기 어려움.
감에 의존해서 쓰다 보니 결과가 일정하지 않음.

## 3. 카피가 매번 비슷해진다

자기도 모르게 같은 표현을 반복 사용.
상품이 다른데 카피가 비슷하면 차별화가 안 됨.

## 4. 외주는 비용 부담이 크다

카피라이터 외주 의뢰 시 건당 3~10만 원.
월 20개 상품 등록 기준 최대 200만 원 — 매출보다 많아질 수 있음.

## 5. 범용 AI 도구는 맥락이 안 맞는다

ChatGPT 등을 써봤지만 스마트스토어 특유의 키워드·검색 최적화를
고려한 카피가 나오지 않음. 결과물을 다듬는 데 또 시간이 걸림.

## 6. 키워드는 있는데 문장을 못 만든다

네이버 키워드 도구로 검색량 높은 키워드는 찾을 수 있음.
그런데 그 키워드를 자연스러운 카피 문장으로 만드는 것이 어려움.
