# PRD — 스마트스토어 카피 생성 도구

## 문제 정의

1인 스마트스토어 셀러는 상품 등록 시 매력적인 카피를 직접 써야 하지만,
글쓰기 역량 부족과 시간 부족으로 경쟁력 있는 문구를 만들기 어렵다.
전문 카피라이터 의뢰는 비용 부담이 크다.

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| 사진 업로드 | 상품 이미지 1장 이상 업로드 (AI가 시각적 특징 분석) |
| 키워드 입력 | 타겟 검색 키워드 최대 5개 입력 |
| 카피 생성 | 위 입력을 바탕으로 카피 3개 자동 생성 |
| 결과 복사 | 생성된 카피를 클립보드로 바로 복사 |

---

## 비기능 요구사항

- 웹 전용 (PC 브라우저)
- 한국어 UI·결과물만
- 카피 생성 응답 10초 이내
- 회원가입 없이 바로 사용 가능 (MVP 기준)

---

## 범위 외 (Out of Scope)

- 모바일 앱
- 다국어 지원
- 스마트스토어 자동 상품 등록
- 카피 이력 저장·관리 (MVP 이후 검토)
